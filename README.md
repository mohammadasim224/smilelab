# SmileLab

Full-screen dental clinic landing page built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**.

## Sections

- **Hero** — full-viewport video background, nav, mobile menu, CTA
- **About** — clinic values and approach
- **Results** — stats and case studies
- **Pricing** — Essential / Smile Design / Family Care plans
- **Reviews** — patient testimonials
- **Blog** — article cards
- **Contacts** — contact info + inquiry form
- **Footer**

## Stack

- React 19
- TypeScript
- Vite 6
- Tailwind CSS v4
- Lucide React icons
- Inter (Google Fonts)

## Design tokens

| Token | Value |
|-------|-------|
| Primary blue | `#5F9AD1` |
| Accent lime | `#EBFA73` |
| Stat blue | `#3D8CD5` |

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (default `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
